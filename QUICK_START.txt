🎯 BUILD STEPS

  Method 1: Android Studio (Easiest)
  ──────────────────────────────────
  1. Download Android Studio
  2. Open /workspaces/CHARU folder
  3. Click Build > Build APK(s)
  4. Find APK at: app/build/outputs/apk/debug/

  Method 2: Command Line
  ──────────────────────
  cd /workspaces/CHARU
  export ANDROID_HOME=/path/to/android/sdk
  ./gradlew build

  Method 3: Quick Build Script
  ─────────────────────────────
  cd /workspaces/CHARU
  ./build.sh

📱 INSTALL ON PHONE

  Using ADB:
  adb install app/build/outputs/apk/debug/app-debug.apk

  Manual:
  1. Copy app-debug.apk to phone
  2. Tap to install
  3. Grant permissions when prompted

  Q: "SDK location not found"

  Q: Build fails with dependencies
  A: This is normal on first build. It downloads dependencies.
